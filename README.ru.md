# Time of Magic

![License](https://img.shields.io/badge/license-MIT-blue.svg) [![Latest Stable Version](https://img.shields.io/packagist/v/stezkoy/flarum-time-of-magic.svg)](https://packagist.org/packages/stezkoy/flarum-time-of-magic) [![Total Downloads](https://img.shields.io/packagist/dt/stezkoy/flarum-time-of-magic.svg)](https://packagist.org/packages/stezkoy/flarum-time-of-magic)

Расширение для Flarum, которое добавляет немного магии на ваш сайт с помощью визуальных улучшений и забавных эффектов.

[English version](README.md)

## Возможности

### Прогресс-бар
Тонкая полоса прогресса под шапкой, которая заполняется при прокрутке страницы. Использует основной цвет вашего сайта.

### Кнопка «Наверх»
Плавающая кнопка, которая появляется после прокрутки вниз. Нажмите на неё, чтобы плавно вернуться наверх.
- Выбор формы: **круг** или **скруглённый квадрат**
- Любой значок **FontAwesome** (например, `fa-solid fa-chevron-up`, `fa-solid fa-angle-double-up`)

### Падающие эффекты
У каждого падающего эффекта **3 уровня плотности** — Лёгкий, Средний и Плотный.

#### Падающий снег
Анимированные снежинки по всему сайту. Идеально подходит для праздничного настроения.
- **Плотность:** Лёгкий (25 снежинок), Средний (50 снежинок), Плотный (75 снежинок)

#### Падающие листья
Анимированные осенние листья, которые кружатся по всему сайту.
- **Плотность:** Лёгкий (10 листьев), Средний (25 листьев), Плотный (40 листьев)

#### Падающий дождь
Эффект дождя с падающими каплями по всему сайту. Цвет автоматически подстраивается под тему.
- **Плотность:** Лёгкий (40 капель), Средний (80 капель), Плотный (140 капель)

#### Цветение сакуры
Лепестки сакуры, дрейфующие по всему сайту.
- **Плотность:** Лёгкий (12 лепестков), Средний (24 лепестка), Плотный (40 лепестков)

#### Конфетти
Цветное конфетти для праздников и вечеринок.
- **Плотность:** Лёгкий (20 элементов), Средний (40 элементов), Плотный (60 элементов)

#### Летящие сердечки
Сердечки, взлетающие вверх ко Дню Святого Валентина.
- **Плотность:** Лёгкий (10 сердечек), Средний (20 сердечек), Плотный (35 сердечек)

#### Четырёхлистные клеверы
Крутящиеся четырёхлистные клеверы ко Дню Святого Патрика.
- **Плотность:** Лёгкий (12 клеверов), Средний (25 клеверов), Плотный (40 клеверов)

#### Пасхальные яйца
Прыгающие пасхальные яйца по всему сайту.
- **Плотность:** Лёгкий (8 яиц), Средний (15 яиц), Плотный (25 яиц)

#### Китайский Новый год
Красные фонарики, драконы и символы удачи к Китайскому Новому году.
- **Плотность:** Лёгкий (10 фонариков), Средний (20 фонариков), Плотный (35 фонариков)

#### Светлячки
Светящиеся светлячки, поднимающиеся вверх летней ночью.
- **Плотность:** Лёгкий (12 светлячков), Средний (25 светлячков), Плотный (40 светлячков)

### Планировщик
Автоматически включает эффекты в заданный период времени. Создайте запись с названием, датой начала и окончания, выберите эффекты (для каждого — свою плотность) и включите её — эффекты будут показываться, пока активно расписание, даже если ручной переключатель выключен.

### Стильный скроллбар
Заменяет стандартный скроллбар браузера на тонкий, оформленный в цветах сайта.

### Искры при клике
Всплеск искр от курсора при каждом клике. Забавная деталь, которая добавляет магии всему сайту.

### Поменять местами сайдбар и контент
Перемещает сайдбар вправо, а список тем влево, придавая форуму уникальный вид.

### Фоновые паттерны
Лёгкие фоновые паттерны, которые работают на светлых и тёмных темах:
- Точки
- Сетка
- Диагональные линии
- Волны
- Гексагоны

### Индивидуальные акцентные цвета
Каждая цветная функция настраивается отдельно и по умолчанию использует цвет вашего форума, если оставить поле пустым:
- Цвет прогресс-бара
- Цвет кнопки «Наверх»
- Цвет скроллбара
- Цвет искр при клике

Принимается любой CSS-цвет, например `#00a185`, `red`, `rgb(255, 0, 0)` — или оставьте пустым, чтобы использовать цвет форума.

## Установка

```bash
composer require stezkoy/flarum-time-of-magic
```

## Требования

- Flarum 2.0
- PHP 8.3+

## Настройка

Все функции настраиваются через **Админ > Расширения > Time of Magic**. Каждую функцию можно включить/выключить независимо.
