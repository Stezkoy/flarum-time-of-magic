# Time of Magic

Расширение для Flarum, которое добавляет немного магии на ваш сайт с помощью визуальных улучшений и забавных эффектов.

[English version](README.md)

## Возможности

### Прогресс-бар
Тонкая полоса прогресса под шапкой, которая заполняется при прокрутке страницы. Использует основной цвет вашего сайта.

### Кнопка «Наверх»
Плавающая кнопка, которая появляется после прокрутки вниз. Нажмите на неё, чтобы плавно вернуться наверх.
- Выбор формы: **круг** или **скруглённый квадрат**
- Любой значок **FontAwesome** (например, `fa-solid fa-chevron-up`, `fa-solid fa-angle-double-up`)

### Падающий снег
Анимированные снежинки по всему сайту. Идеально подходит для праздничного настроения.
- **3 уровня плотности:** Лёгкий (25 снежинок), Средний (50 снежинок), Плотный (75 снежинок)

### Стильный скроллбар
Заменяет стандартный скроллбар браузера на тонкий, оформленный в цветах сайта.

### Поменять местами сайдбар и контент
Перемещает сайдбар вправо, а список тем влево, придавая форуму уникальный вид.

### Фоновые паттерны
Лёгкие фоновые паттерны, которые работают на светлых и тёмных темах:
- Точки
- Сетка
- Диагональные линии
- Волны
- Гексагоны

## Установка

```bash
composer require stezkoy/flarum-time-of-magic
```

## Требования

- Flarum 2.0
- PHP 8.3+

## Настройка

Все функции настраиваются через **Админ > Расширения > Time of Magic**. Каждую функцию можно включить/выключить независимо.
